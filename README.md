## Hi, I'm Írcaro 👋

- 🧪 SDET / QA Engineer from Salvador, Brazil.
- 🎓 Computer Science at Unifacs (in progress).
- 💳 Working at Zig since 2022 on the quality of a payments platform: contracts, fees, operational closing and refunds.
- 🔧 I don't stop at the bug report. I trace the defect to the layer where it was born and ship the fix, in TypeScript and C#.
- 🎮 I like video games, so I build a few of them too.

### What I work on

- **API test automation** with PactumJS, Mocha and TypeScript, built on services, data builders and factories that stay cheap to maintain.
- **Root cause across systems.** I follow the data from the admin panel to the legacy service and the database, in financial flows where "it looks wrong" means money.
- **Production code.** Features and fixes in a Node.js API, React admin panels and .NET services, behind feature flags.
- **Removing manual work.** One example: a pricing-floor exception flow that turned 44 manual production database scripts into zero, with approvals recorded in the system.
- **AI-assisted QA tooling.** Claude Code skills that audit the team's board and post the report to Slack, run ad-hoc API checks during investigations and standardize read-only database access.
- **Shift left.** I join refinement and prototype reviews to catch integration problems before any code exists.
